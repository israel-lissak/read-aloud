# הקראה — קריאה והאזנה לכתבות

מדביקים קישור לכתבה, והאפליקציה מחלצת את הטקסט הראשי, מציגה אותו בתצוגת קריאה נקייה ומקריאה אותו בקול (Web Speech API), עם הדגשה של המשפט והמילה הנוכחיים.

## התקנה

נדרש Node.js 20 ומעלה.

```bash
npm install
```

## הרצה

**פיתוח** (שרת API על פורט 3001 + Vite על 5173, עם proxy ל־`/api`):

```bash
npm run dev
```

פותחים את http://localhost:5173

**ייצור:**

```bash
npm run build
npm start
```

השרת מגיש גם את ה־API וגם את קבצי `dist` בכתובת http://localhost:3001 (אפשר לשנות עם משתנה הסביבה `PORT`).

**בדיקות:** `npm run typecheck`

אפשר גם לפתוח ישירות כתבה דרך הכתובת: `http://localhost:5173/?url=https://...`

## שימוש

- לחיצה על משפט מתחילה את ההקראה ממנו.
- <kbd>רווח</kbd> — הקראה/השהיה, <kbd>←</kbd>/<kbd>→</kbd> — משפט קודם/הבא.
- היסטוריה: כתבות שנפתחו מוצגות במסך הפתיחה (לחיצה על הלוגו חוזרת אליו), כולל המיקום שבו עצרתם — פתיחה מחדש ממשיכה משם. נשמרת בדפדפן (עד 50 כתבות).
- בהגדרות: גופן, גודל, ריווח שורות, ערכת צבעים, קול (נשמר לכל שפה בנפרד) ומהירות. ההגדרות נשמרות בדפדפן.

## מבנה

- `server.ts` — שרת Express: `GET /api/extract?url=` מוריד את העמוד (עם הגנת SSRF בסיסית, זיהוי קידוד כולל windows-1255), מחלץ עם Readability ומחזיר `{ title, lang, blocks }`.
- `src/hooks/useTTS.ts` — מנוע ההקראה: utterance לכל משפט, השהיה/המשך מהמילה האחרונה בלי `speechSynthesis.pause`.
- `src/lib/sentences.ts` — פיצול למשפטים (`Intl.Segmenter`) ופיצול משפטים ארוכים בפסיקים.

## מגבלות ידועות

- **אתרים שנבנים ב־JavaScript** (SPA) — השרת לא מריץ JavaScript, ולכן עמודים שהתוכן שלהם נטען בצד הלקוח יחזירו מעט טקסט או שגיאה.
- **חומות תשלום והתחברות** — כתבות שדורשות מנוי או התחברות יחזירו רק את הפתיח או דף חסימה. אתרים מסוימים גם חוסמים גישה אוטומטית.
- **עמודי בית ורשימות** — Readability מיועד לכתבות; בעמוד בית התוצאה תהיה חלקית.
- **הבדלים בין דפדפנים בהדגשת מילים** — הדגשת המילה תלויה באירועי `boundary`:
  - קולות הרשת של Google ב־Chrome לא שולחים אירועים אלה, ולכן ההדגשה תהיה ברמת משפט בלבד, והמשך אחרי השהיה יתחיל מתחילת המשפט. לכן נבחר כברירת מחדל קול מקומי כשיש כזה.
  - ב־Safari, Edge (קולות Microsoft) ו־Android התמיכה משתנה בין גרסאות וקולות.
- **קולות בעברית** — זמינים רק אם מותקנים במערכת ההפעלה (למשל "Asaf" ב־Windows, "Carmit" ב־macOS/iOS). אם אין קול עברי, ההקראה תיעשה בקול ברירת המחדל.
- **SSRF** — ההגנה בודקת את כתובות ה־IP לפני כל בקשה וכל הפניה, אבל אינה מגינה מפני DNS rebinding. אין לחשוף את השרת לאינטרנט בלי שכבת הגנה נוספת.
- עמודים גדולים מ־8MB או שלא מגיבים תוך 15 שניות נדחים.
